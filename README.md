# Laxhya IT Support Portfolio

A responsive, data-driven portfolio for IT Support, Service Desk, Endpoint, Microsoft 365 and Cloud Support professionals.

## Quick start

1. Extract the ZIP.
2. Open **config.js** and replace the example profile and work history.
3. Open **index.html** in a current browser.
4. For local development, use a static server such as the VS Code Live Server extension.

No package installation or build command is required.

## Edit your content

Nearly all personal content is stored in **config.js**:

- profile: name, portrait image, rotating roles, introduction, location and contact links
- heroTags: first-screen technologies
- about: profile summary, measurable results and working principles
- experience: role history and responsibilities
- skills: filterable technical skills
- projects: project cards, outcomes and modal details
- achievements: certifications, recognition and milestones
- emailjs: optional direct contact-form delivery

## Project files

| File | Purpose |
| --- | --- |
| index.html | Accessible page structure and metadata |
| styles.css | Responsive layout, theme and motion |
| config.js | Portfolio content and contact configuration |
| app.js | Rendering, filters, navigation, modal and form behavior |
| assets/ | Favicon, resume and optional project images |
| SETUP_GUIDE.md | Detailed setup, customization and deployment guide |

The included Word guide provides extended onboarding material in a print-friendly format.

## Design and accessibility

- Responsive layouts for desktop, tablet and mobile
- Keyboard-accessible controls and visible focus states
- Reduced-motion support
- Active-section navigation
- Scroll reveal, pointer lighting and restrained 3D hover effects
- Configurable hero profile photo with an automatic initials fallback
- No horizontal page overflow at supported viewport sizes

## Deployment

The project can be published directly with GitHub Pages, Netlify, Cloudflare Pages or any static host. Keep the HTML, CSS, JavaScript and assets together.

See **SETUP_GUIDE.md** for complete instructions.
