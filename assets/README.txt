LAXHYA AEGIS IT SUPPORT PORTFOLIO - OPTIONAL ASSETS

You can place optional files here.

Recommended examples:

resume.pdf
profile-photo.webp
project-automation.webp
project-onboarding.webp
project-knowledge-hub.webp
project-endpoint-health.webp

Update config.js after adding a file.

Resume example:
resume: "assets/resume.pdf"

Profile photo example:
photo: "assets/profile-photo.webp"
photoAlt: "Portrait of Your Name"
photoPosition: "50% 35%"

Project image example:
image: "assets/project-automation.webp"

If a project image is left blank, the portfolio automatically uses its built-in gradient artwork.

Recommended project image ratio:
16:10 or 16:9

Recommended profile photo ratio:
4:5 portrait

Recommended formats:
WebP, JPG, PNG

Do not include confidential screenshots, passwords, private IP addresses, customer data, ticket contents or other restricted business information.
